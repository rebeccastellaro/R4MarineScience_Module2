1.9 Integrating data grammar with visual diagnostics

Direct piping: mean body mass by species and island

Rather than saving an intermediate summary table, this pipes the aggregation straight into ggplot() which is efficient for rapid exploratory visualisation. Error bars show standard deviation.

Code 
mass_compare_plot <- penguins |>
  group_by(species, island) |>
  summarise(
    mean_mass = mean(body_mass_g, na.rm = TRUE),
    sd_mass = sd(body_mass_g, na.rm = TRUE),
    n = n(),
    .groups = "drop"
  ) |>
  ggplot(aes(x = species, y = mean_mass, colour = island)) +
  geom_point(size = 3) +
  geom_errorbar(aes(ymin = mean_mass - sd_mass,
                     ymax = mean_mass + sd_mass),
                width = 0.2) +
  labs(title = "Mean Body Mass by Species and Island",
       subtitle = "Error bars represent standard deviation",
       y = "Mean Body Mass (g)",
       x = "Species") +
  theme_minimal()

mass_compare_plot

What this shows: Gentoo penguins are clearly heavier on average than Adelie or Chinstrap, and the pattern holds consistently across islands, so species is doing more work than location here. The relatively small error bars suggest pretty consistent body mass within each species/island group, rather than huge individual variation.

Challenge: swapping standard deviation for standard error

Standard error (sd / sqrt(n)) accounts for sample size, so it shrinks as more individuals are measured. It estimates uncertainty in the mean itself, rather than describing the spread of raw individual measurements the way standard deviation does.

Code 
mass_compare_plot_se <- penguins |>
  group_by(species, island) |>
  summarise(
    mean_mass = mean(body_mass_g, na.rm = TRUE),
    sd_mass = sd(body_mass_g, na.rm = TRUE),
    n = sum(!is.na(body_mass_g)),
    std_error = sd_mass / sqrt(n),
    .groups = "drop"
  ) |>
  ggplot(aes(x = species, y = mean_mass, colour = island)) +
  geom_point(size = 3) +
  geom_errorbar(aes(ymin = mean_mass - std_error,
                     ymax = mean_mass + std_error),
                width = 0.2) +
  labs(title = "Mean Body Mass by Species and Island",
       subtitle = "Error bars represent standard error",
       y = "Mean Body Mass (g)",
       x = "Species") +
  theme_minimal()

mass_compare_plot_se

Comparing the two: the standard error bars are noticeably tighter than the standard deviation bars and this is because SE reflects confidence in the estimated mean, not the raw spread of individual penguins. With SE bars, species differences look even more clearly separated and statistically convincing, because we’re not being visually distracted by individual variation within each group.

Reflection

Writing this workshop’s code manually rather than leaning on Copilot forced me to actually read every error message R gave me instead of skimming past it, and to keep track of variable types as I went rather than assuming they were correct. The clearest example was the “Missing Value Trap” in section 1.8 where summarise() silently returned NA for groups with missing values until I explicitly added na.rm = TRUE, which wouldn’t have been obvious at first. Comparing the tibble vs the old data.frame also made more sense doing it manually, actually seeing the tibble reject a partial column match instead of silently guessing what I meant made it obvious why that’s a safety feature.
